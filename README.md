# NN118 Live Display

Static web replica of the NN118 round temperature/humidity display (SUNY Canton RAISE Lab).

- Room data: public ThingSpeak channel [3535007](https://thingspeak.mathworks.com/channels/3535007)
- Outdoor data: [Open-Meteo](https://open-meteo.com/) for Canton, NY
- Refreshes every 30 s; single `index.html`, no build step.

Live: https://carrollj13633.github.io/nn118-live-display/
